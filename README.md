# Naruto Jutsu (mod NeoForge 1.21.1)
Mod de fan, non officiel. Chakra (HUD en bas a gauche), parchemin Katon (boules de feu), parchemin Shunshin (dash).

## Obtenir le .jar sans installer Java
1. Cree un depot GitHub, envoie-y tout ce dossier.
2. Onglet Actions > "Build mod" > ouvre l'execution > Artifacts > naruto-mod-jar.
3. Mets le .jar dans le dossier mods de NeoForge 1.21.1.

## En local
Java 21 + Gradle 8.10 : `gradle build` puis `gradle runClient`.
Le .jar est dans build/libs/.
